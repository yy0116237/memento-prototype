# Memento 项目存档

Memento（定格）是一款帮助用户将现场经历（演出 / 展览 / 比赛 / 旅行等）沉淀为可收藏「记忆卡片」与分享「海报」的记录产品。

## 仓库内容

| 文件 | 说明 |
| --- | --- |
| `Memento PRD2.0.docx` | 产品文档：信息架构、双轨字体方案、三语（中/英/韩）适配、半圆时钟双模式、Snap/Murmur 输入、竖向时间线、海报四层结构等 |
| `memento_visual_prototype.html` | 可视化原型（单文件 HTML）：灰蜡笔手绘边框 + 沙沙噪点、双轨字体、右上角三语切换、半圆时钟指针双模式 Toggle、Snap/Murmur 输入、竖向时间线 + 便利贴弹窗 + 高斯模糊、海报生成与展示（四层结构 + 第 4 层铅笔手写下沉起伏下划线 + 第 2 层深灰文字区分 + html2canvas 导出） |

## 预览原型

直接用浏览器打开 `memento_visual_prototype.html` 即可（需联网加载部分 CDN 字体 / 导出库）。

## 版本

- PRD 2.0 + 可视化原型（截至 2026-07-21）
